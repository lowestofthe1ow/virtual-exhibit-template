## The Problem: The Physics Wall

The bigger a die becomes, the more surface area it exposes to random manufacturing defects. A defect that lands on a single monolithic CPU die can scrap the entire part, so high-performance processors eventually run into a cost wall as much as a physics wall.

<PhysicsWall />

## The Solution: Before vs. After

Chiplets change the unit of failure. A flawed small die can be discarded while the known-good dies from the same wafer still have value, which lets designers compose a large processor from parts that are easier to manufacture.

<BeforeAfter />

## Infinity Fabric: The Highway Between Chiplets

AMD's chiplet strategy only works if the smaller dies can talk like one processor. Infinity Fabric is the on-package and system-level interconnect that carries coherent traffic between CPU cores, chiplets, memory controllers, PCIe, and sockets. In the first EPYC generation, AMD described Infinity Fabric as the coherent interconnect for two EPYC CPUs in a dual-socket system. In Rome, NASA's HECC overview describes Infinity Fabric connecting cores, CCXs, CCDs, the I/O die, main memory, PCIe, and the second socket.

Infinity Fabric operates at speeds tied to the memory clock, delivering low-latency, high-bandwidth communication between components. In Rome, each CCD connects to the central I/O die through dedicated Infinity Fabric links, giving the package a star topology rather than the more distributed layout of Naples. This architecture reduced worst-case core-to-memory latency and simplified NUMA balancing for operating systems.

## Naples to Rome: The Architectural Break

First-generation EPYC, code-named Naples, already pushed server CPUs with a 32-core SoC design, eight memory channels, 128 lanes of PCIe 3.0, and Infinity Fabric for dual-socket coherence. It proved AMD could compete in servers, but it still carried more I/O and memory-controller duplication across its multi-die arrangement.

Rome, the second-generation EPYC 7002 platform, made the bigger break. AMD moved to Zen 2 cores, up to 64 cores and 128 threads, 128 lanes of PCIe 4.0, and a hybrid multi-die structure: eight 7 nm CCDs around one larger I/O die. AMD's own Zen architecture page frames chiplets as the scalable alternative to building larger monolithic dies.

## Metrics Dashboard

<Metrics />

These three numbers describe the same shift from different angles. By splitting designs into chiplets manufactured at high yield, AMD reduced estimated per-processor manufacturing costs by over 40% compared to a hypothetical monolithic die of equivalent core count. Yield Improvement Rate captures how many more usable chips can come out of a wafer once the design is divided into chiplets instead of staying one giant die. Die Cost Reduction follows directly from that: smaller dies are cheaper to fabricate at high yield, so the cost per functional core drops even as total core count goes up.

Scalability Factor is what all of that buys AMD in practice. Because chiplets are stitched together with high-speed interconnects rather than fused into one continuous die, AMD is no longer limited by the economics of one ever-larger die. Instead of trying to make one enormous die reliable, AMD links smaller, reliably manufactured ones and lets core counts climb.

## Key Terms

<dl className="chip-rev-terms">
  <div>
    <dt>Chiplet</dt>
    <dd>A small functional die designed to be combined with other dies in the same processor package.</dd>
  </div>
  <div>
    <dt>CCD</dt>
    <dd>Core Complex Die. In Rome, each CCD contains CPU core complexes and connects back to the I/O die.</dd>
  </div>
  <div>
    <dt>IOD</dt>
    <dd>I/O die. The centralized die that carries memory controllers, PCIe connectivity, and package-level routing.</dd>
  </div>
  <div>
    <dt>Infinity Fabric</dt>
    <dd>AMD's coherent interconnect for moving data among cores, chiplets, memory, I/O, and sockets.</dd>
  </div>
  <div>
    <dt>Reticle limit</dt>
    <dd>The maximum area a lithography exposure can print at once, creating a practical ceiling for single-die scaling.</dd>
  </div>
  <div>
    <dt>Known-good die</dt>
    <dd>A manufactured die that passes testing and can be used in a package instead of being scrapped.</dd>
  </div>
  <div>
    <dt>CCX (Core Complex)</dt>
    <dd>A cluster of CPU cores sharing an L3 cache. Multiple CCXs make up a CCD in AMD's Zen architecture.</dd>
  </div>
  <div>
    <dt>Defect Density</dt>
    <dd>The average number of fatal manufacturing defects per unit area on a wafer, typically measured in defects per cm².</dd>
  </div>
  <div>
    <dt>Yield</dt>
    <dd>The percentage of manufactured dies that pass testing and are functional. Higher yield means less wasted silicon and lower cost per working chip.</dd>
  </div>
</dl>
