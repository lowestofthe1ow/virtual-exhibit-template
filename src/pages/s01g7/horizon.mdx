<section id="intro">
  <h2>Introduction</h2>
  <p style="text-align: justify;">
    As technology continues to evolve, the way we store data is changing faster than
    ever. From cloud storage that lets us access files anytime and anywhere, to
    experimental technologies like DNA storage that could preserve vast amounts of
    information in an incredibly small space, the future of data storage is becoming
    more powerful, scalable, and innovative.
  </p>
  <p style="text-align: justify;">
    This section explores how modern cloud systems store and manage data, the role
    of data centers and distributed storage in keeping information secure and
    available, and the emerging technologies that may shape the next generation of
    digital storage. Together, these advancements provide a glimpse into the future
    of how the world's growing data will be stored, protected, and accessed.
  </p>
</section>

<section id="cloud-architecture">
  <h2>Cloud Storage Architecture</h2>

  <figure class="figure-placeholder">
    <img src={cloudArchitecture.src} alt="Diagram of cloud storage architecture components" class="figure-img figure-img-cloud" />
    <figcaption>Fig. Cloud Storage Architecture</figcaption>
  </figure>

  <p style="text-align: justify;">
    Cloud storage architecture is the framework that enables users to store, manage,
    and access data through the internet instead of relying solely on local storage
    devices. It consists of four main components: the front-end, back-end, network,
    and cloud-based delivery platform. The front-end is the user side, where people
    interact with cloud services using applications or web browsers on devices such
    as laptops, smartphones, and tablets. The network, usually the internet,
    securely connects users to the cloud service provider. The back-end contains the
    remote servers, databases, storage systems, and management software that process
    requests and store data in data centers. Together, these components allow users
    to upload, retrieve, and synchronize files efficiently from virtually anywhere
    with an internet connection. Cloud storage architecture provides flexibility,
    scalability, reliability, and secure access to digital information, making it an
    essential part of modern computing.
  </p>

  <p style="text-align: justify;">
    Cloud storage enables individuals and organizations to store, access, and manage
    data through remote servers hosted by cloud service providers instead of relying
    on local storage devices. One of its greatest advantages is scalability, which
    allows storage capacity to expand or shrink based on changing data needs. As
    users create more data, cloud providers can allocate additional storage
    resources without requiring new physical hardware or disrupting existing
    services. This flexibility allows businesses to handle growing workloads
    efficiently while paying only for the resources they use. By combining
    scalability with secure remote access and reliable storage, cloud computing
    provides a cost-effective solution that supports the increasing demand for
    digital data in today's connected world.
  </p>
</section>

<section id="data-access">
  <h2>Data Access and Retrieval</h2>

  <CloudDataFlow client:load />

  <p style="text-align: justify;">
    Cloud storage systems are designed to locate and retrieve data quickly and
    efficiently, even when billions of files are stored across multiple servers.
    When a user requests a file, the system uses indexing to identify its location,
    while metadata provides descriptive information such as the file name, type,
    owner, and creation date. Frequently accessed files may be stored in a cache,
    allowing them to be retrieved much faster without searching the entire storage
    system. Networking enables secure communication between users and cloud
    servers, while load balancing distributes requests across multiple servers to
    prevent congestion and maintain fast performance. Together, these technologies
    ensure that users can access their files reliably, often within milliseconds.
  </p>

<section id="data-centers">
  <h2>Data Centers</h2>

  <figure class="figure-placeholder">
    <img src={dataCenter.src} alt="Photo of a modern data center with server racks" class="figure-img figure-img-datacenter" />
    <figcaption>Fig. Modern Data Center <a href="https://www.hiclipart.com/free-transparent-background-png-clipart-donyq" target="_blank" rel="noopener">(HiClipart)</a></figcaption>
  </figure>

  <p style="text-align: justify;">
    A data center is a physical facility that houses the servers, storage devices,
    networking equipment, and other IT infrastructure needed to store, process, and
    manage digital information. Instead of keeping data on a user's personal
    computer, cloud service providers store data in large data centers that operate
    continuously to ensure information is always available. Modern data centers
    contain thousands of interconnected servers organized in racks and are equipped
    with advanced cooling systems, backup power supplies, and security measures to
    maintain reliable operation. By distributing data across multiple servers and
    locations, data centers provide high availability, fast access, and protection
    against hardware failures or unexpected disasters, making them the foundation of
    today's cloud computing services.
  </p>
</section>

      </div>
    </div>
    <div class="tree-footer">🛡️ Backup + Redundancy — extra copies stored elsewhere</div>
  </div>

  <p style="text-align: justify;">
    A distributed storage system is a method of storing data across multiple
    interconnected servers or storage nodes instead of keeping all information in a
    single location. By distributing data across different machines, the system
    becomes more scalable, reliable, and fault tolerant, ensuring that information
    remains available even if one server fails. To improve data reliability,
    distributed storage systems use techniques such as <strong>replication</strong>,
    which creates multiple copies of data on different servers;
    <strong>sharding</strong>, which divides large datasets into smaller pieces
    stored across several nodes; <strong>backup</strong>, which provides additional
    copies for recovery after failures or disasters; and <strong>redundancy</strong>,
    which adds extra storage resources to prevent data loss. These techniques work
    together to improve performance, maintain continuous access to data, and support
    the large-scale storage needs of modern cloud computing services.
  </p>
</section>

<section id="dna-storage">
  <h2>DNA Storage</h2>

  <figure class="figure-placeholder">
    <img src={dnaStorage.src} alt="Illustration of DNA strands used for digital data storage" class="figure-img figure-img-dna" />
    <figcaption>Fig. Illustration of Synthetic DNA Strand with Data Encoded <a href="https://www.geneticsdigest.com/the-role-of-dna-data-storage-in-health-and-technology/" target="_blank" rel="noopener">(Genetics Digest)</a></figcaption>
  </figure>

  <p style="text-align: justify;">
    DNA storage is an emerging technology that uses synthetic DNA molecules to store
    digital information instead of traditional storage devices such as hard drives
    or solid-state drives. Instead of recording data as binary digits (0s and 1s),
    DNA storage converts digital information into sequences of the four DNA bases:
    <strong>A</strong> (Adenine), <strong>T</strong> (Thymine), <strong>C</strong>
    (Cytosine), and <strong>G</strong> (Guanine). These DNA strands are then
    synthesized, preserved in secure containers, and can later be sequenced to
    retrieve the original digital data. Because DNA has an extremely high storage
    density, a tiny sample can theoretically hold enormous amounts of information
    while requiring very little physical space. Researchers have already
    demonstrated this potential by storing books, movies, and other digital files in
    DNA. Although DNA storage promises exceptional capacity, long-term durability,
    and energy-efficient archiving, it is still in the experimental stage due to the
    high cost and slow process of writing and retrieving data.
  </p>

<section id="holographic-storage">
  <h2>Holographic Storage</h2>

  <figure class="figure-placeholder">
    <img src={holographicStorage.src} alt="Diagram of holographic data storage using lasers" class="figure-img figure-img-holo" />
    <figcaption>Fig. — Lasers record and read data across the full depth of a holographic medium <a href="https://www.thehindu.com/sci-tech/technology/microsofts-exploring-holographic-storage-devices-for-its-cloud-what-does-it-mean/article61735059.ece" target="_blank" rel="noopener">(The Hindu)</a></figcaption>
  </figure>

  <p style="text-align: justify;">
    Holographic storage is an emerging data storage technology that uses lasers to
    record and retrieve digital information in three dimensions. Unlike traditional
    optical storage devices such as CDs and DVDs that store data only on their
    surface, holographic storage records data throughout the entire volume of a
    light-sensitive material, allowing much more information to be stored in the
    same physical space. This technology offers the potential for high storage
    capacity, fast data transfer, and quick access to large amounts of information,
    making it a promising solution for cloud storage, data centers, and big data
    applications. Although researchers and companies such as Microsoft continue to
    develop holographic storage systems, the technology is still in the research
    stage and has not yet been widely commercialized due to technical and
    manufacturing challenges.
  </p>
</section>

  <p style="text-align: justify;">
    Neuromorphic storage is an emerging technology inspired by the way the human
    brain stores and processes information. Unlike traditional storage systems that
    separate memory from processing, neuromorphic storage combines both functions
    into a single system, allowing data to be stored, processed, and retrieved more
    efficiently. Using advanced nanophotonic materials and brain-inspired
    architectures, it can mimic neural connections that learn, adapt, and perform
    many operations simultaneously. This approach has the potential to significantly
    reduce energy consumption while providing faster data access and higher storage
    performance. Although still in the research stage, neuromorphic storage is
    considered a promising technology for supporting future applications such as
    artificial intelligence, machine learning, and large-scale cloud computing.
  </p>

        way of storing and processing information to support future artificial
        intelligence and cloud computing.
