# Cloud Storage Glossary

## Accessibility
The ability to access files from any location using an Internet-connected device.

---

## Authentication
The process of verifying a user's identity before granting access to cloud resources.

---

## Authorization
The process of determining what resources and actions an authenticated user is permitted to access.

---

## Cloud Computing
The delivery of computing services—including storage, servers, networking, and software—over the Internet.

---

## Cloud Service Provider (CSP)
A company that provides cloud computing services, such as Google, Microsoft, Amazon, or Apple.

---

## Cloud Storage
A method of storing digital data on remote servers managed by a cloud service provider and accessed through the Internet.

---

## Data Center
A physical facility that houses servers, storage devices, networking equipment, power systems, and cooling infrastructure used to provide cloud services.

---

## Data Packet
A small unit of data transmitted across a network during file transfer.

---

## Distributed Storage
A storage architecture in which data is spread across multiple servers instead of being stored on a single machine.

---

## Elasticity
The ability of cloud storage systems to automatically increase or decrease storage resources based on demand.

---

## Encryption
The process of converting readable data into an unreadable format to protect it from unauthorized access.

---

## Encryption at Rest
Encryption applied to files while they are stored on cloud servers.

---

## Encryption in Transit
Encryption that protects data while it is being transferred across a network.

---

## Fault Tolerance
The ability of a system to continue operating even when one or more components fail.

---

## Hard Disk Drive (HDD)
A traditional magnetic storage device commonly used for large-capacity data storage.

---

## High Availability
A design principle that ensures cloud services remain continuously accessible with minimal downtime.

---

## HTTPS
A secure communication protocol used to protect data transmitted over the Internet.

---

## Metadata
Information that describes a file, such as its name, owner, size, upload date, and permissions.

---

## Multi-Factor Authentication (MFA)
A security method requiring two or more forms of verification before granting access.

---

## Redundancy
The practice of storing multiple copies of data to improve reliability and prevent data loss.

---

## Remote Server
A computer located in a data center that stores and processes user data.

---

## Replication
The automatic creation of multiple copies of a file across different storage servers.

---

## Scalability
The ability of a cloud storage system to increase or decrease storage capacity as needed.

---

## Solid State Drive (SSD)
A high-speed storage device that stores data using flash memory.

---

## Storage as a Service (StaaS)
A cloud computing service model that provides storage resources over the Internet.

---

## Storage Cluster
A group of interconnected storage servers that function as a single storage system.

---

## Storage Virtualization
The process of combining multiple physical storage devices into one logical storage system.

---

## Synchronization
The automatic updating of files across multiple connected devices.

---

## TLS (Transport Layer Security)
A cryptographic protocol used to secure communications over the Internet.

---

## Upload
The process of transferring data from a user's device to a cloud storage service.
